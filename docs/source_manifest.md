# FORGEIQ Source Manifest

## 1. Data Provenance

FORGEIQ uses synthetic manufacturing data generated locally by Python scripts.

No real customer, supplier, employee, or production-system records are used.

## 2. Generation Configuration

Configuration file: `generator/config.py`

| Parameter | Value |
|---|---:|
| Random seed | 20261022 |
| Products | 100 |
| Machines | 40 |
| Materials | 200 |
| Operations per routing | 4 |
| Production orders | 500 |
| Order operations | 2,000 |
| Generation start date | 2026-11-01 |
| Generation horizon | 30 days |

The fixed seed supports repeatable generation when the same code, configuration, and dependencies are used.

## 4. Reproduction Commands

Run commands from the project root directory.

Generate master data:

```bash
python -m generator.master_data
```

Generate transactional data:

```bash
python -m generator.transaction_data
```

Generate anomaly fixtures and ground truth:

```bash
python -m generator.anomaly_generator
```

Run manufacturing validation:

```bash
python -m validations.validators
```

Run anomaly evaluation:

```bash
python -m validations.evalute
```

Run the test suite:

```bash
python -m pytest tests/ -v
```

The pilot schedule is generated through the scheduling workflow or the API's `/optimize` endpoint.

## 6. Reproducibility Notes

- The random seed is defined in `generator/config.py`.
- Generated CSV files are stored under `data/`.
- The SQLite database is created locally and is excluded from Git.
- The pilot optimizer currently schedules a subset of 20 orders and 80 operations.
- Solver output may vary with dependency versions, solver behavior, and runtime conditions.
- A feasible solver result does not imply proven optimality.

## 7. Known Data Limitations

- All manufacturing records are synthetic.
- The pilot optimizer operates on a subset of the full production-order dataset.
- The five injected anomaly scenarios are designed for validator evaluation.
- The anomaly evaluation score measures detection against those injected scenarios, not performance on real factory data.
